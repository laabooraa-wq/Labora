Reglas de cálculo (obligatorias)

Almacena tiempos en UTC y renderiza en TZ del perfil (Europe/Madrid por defecto).

Trabaja en minutos.

Prioridad por minuto: nocturna > extra > complementaria > normal.

Pausa: breaksMinutes se resta antes de clasificar.

Colas: complementaryMinutes y overtimeMinutes se aplican al final del turno. Si caen en franja nocturna, se pagan como nocturnos (la nocturna manda).

Turno extra (isExtraShift): etiqueta para informes; no altera tarifas por sí misma.

PTO (vacaciones/compensatoria):

H_dia = H_sem / D_sem; minutos = paidMinutesOverride ?? round(H_dia*60); € = horas * tarifa base (con overrideRates.base si viene de import “base solo/escalar”).

No aplica nocturna/extra/complementaria.

Descanso: €=0. Baja (MVP): €=0.

Cambios de tarifas/franja: recalcular histórico (invalidar calcCache y recomputar bajo demanda).

Validaciones

Duración efectiva > 0.

complementaryMinutes + overtimeMinutes ≤ duración efectiva.

Sin solapes (bloquear o pedir confirmación).

Si existe un día especial en esa fecha: al crear turno normal, pedir confirmación para sustituir; en import, ofrecer mantener/sustituir.

Notas de range: 0 ≤ startOffsetMin < endOffsetMin ≤ duración.

Import:

Ignorar filas 00:00–00:00.

Si modo “base solo/escalar” y falta Precio → degradar a “No usar” + aviso.

Si “ajustar a Importe” y falta Importe → ignorar lock + aviso.

export type DayKind = 'normal' | 'descanso' | 'vacaciones' | 'compensatoria' | 'baja';
export type ShiftType = 'generico' | 'complementario' | 'adquirido';
export type AnnotationScope = 'whole' | 'complementaryTail' | 'overtimeTail' | 'range';

export interface UserProfile {
  uid: string; email: string;
  currency: 'EUR';
  timezone: string; // "Europe/Madrid"
  theme: 'light'|'dark'|'system';
  rates: { base:number; extra:number; night:number; complementary?:number };
  nightWindow: { from:string; to:string };
  contract: { hoursPerWeek:number; workDaysPerWeek:number };
  createdAtISO: string; updatedAtISO: string;
}

export interface Annotation {
  id: string;
  scope: AnnotationScope;
  startOffsetMin?: number;
  endOffsetMin?: number;
  text: string;
  tags?: string[];
  createdAtISO: string;
}

export interface Shift {
  id: string; uid: string;
  kind: DayKind;
  dateISO: string;             // YYYY-MM-DD (TZ del usuario)
  // kind === 'normal':
  startISO?: string;           // UTC
  endISO?: string;             // UTC
  breaksMinutes?: number;
  complementaryMinutes?: number;
  overtimeMinutes?: number;
  isExtraShift?: boolean;
  extraShiftInfo?: { colleagueName?: string };
  type?: ShiftType;
  annotations?: Annotation[];
  // kind !== 'normal':
  paidMinutesOverride?: number;
  // import overrides:
  overrideRates?: { base?:number; extra?:number; night?:number; complementary?:number };
  eurosOverride?: number;
  source?: {
    origin: 'manual'|'import';
    fileName?: string; fileRow?: number;
    filePrice?: number; fileAmount?: number;
    appliedMode?: 'none'|'file-base'|'file-scaled'|'file-amount-lock';
  };
  calcCache?: { baseMin:number; extraMin:number; nightMin:number; euros:number };
  createdAtISO: string; updatedAtISO: string;
}

Motor de cálculo (pseudocódigo clave)
function computeShiftEuros(shift: Shift, profile: UserProfile) {
  if (shift.kind !== 'normal') return computePTOorRest(shift, profile);

  const tariffs = { ...profile.rates, ...shift.overrideRates };
  const timeline = expandMinutes(shift.startISO, shift.endISO); // maneja cruce
  let minNormal=0, minNight=0;

  for (const minute of timeline) {
    if (!isInBreak(minute, shift.breaksMinutes)) {
      if (isInNight(minute, profile.nightWindow, profile.timezone)) minNight++;
      else minNormal++;
    }
  }

  // aplicar colas complementaria y luego extra, sin romper prioridad nocturna
  let comp = Math.min(shift.complementaryMinutes ?? 0, minNormal);
  minNormal -= comp;
  let extra = Math.min(shift.overtimeMinutes ?? 0, minNormal);
  minNormal -= extra;

  // los “restos” de comp/extra que caigan en nocturna NO desplazan minNight (nocturna manda)

  const euros =
    (minNormal/60)*tariffs.base +
    (comp/60)*(tariffs.complementary ?? tariffs.base) +
    (extra/60)*tariffs.extra +
    (minNight/60)*tariffs.night;

  return {
    baseMin: minNormal, extraMin: extra, nightMin: minNight,
    euros: shift.eurosOverride ?? round2(euros)
  };
}

function computePTOorRest(shift: Shift, profile: UserProfile) {
  if (shift.kind === 'descanso' || shift.kind === 'baja') {
    return { baseMin:0, extraMin:0, nightMin:0, euros:0 };
  }
  const base = (shift.overrideRates?.base ?? profile.rates.base);
  const Hdia = profile.contract.hoursPerWeek / profile.contract.workDaysPerWeek;
  const paidMin = shift.paidMinutesOverride ?? Math.round(Hdia*60);
  const euros = (paidMin/60) * base;
  return { baseMin: paidMin, extraMin:0, nightMin:0, euros: round2(euros) };
}
